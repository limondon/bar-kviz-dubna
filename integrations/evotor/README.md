# 1708 — касса (тест), 0.3 — локальная подготовка

Android-прототип для проверки официального SDK Эвотора и передачи состава стола из сайта. APK не входит в сборку сайта. Версия 0.3 добавляет каталог реальных кассовых карточек и общие редактируемые соответствия в разделе сайта «Ещё → Касса Эвотор». Новые товары, добавки и состав из нескольких карточек настраиваются через интерфейс. Описание, схема данных и границы проверки: [SETTINGS-0.3.md](SETTINGS-0.3.md). Пароль и токены не сохраняются на диске. Команд оплаты и печати нет. Обычный экран кассы имеет свои кнопки оплаты: тестовый чек оплачивать нельзя.

Версия 0.1 установлена пользователем через тестирование Эвотора; по фотографиям подтверждены чтение карточки «Безалкогольное пиво» (200 ₽, SERVICE), открытие стандартного незакрытого чека ×1 и последующее удаление тестовой позиции (подтверждено пользователем). Это не проверка остальных товаров и алкоголя. Версии 0.2 и 0.3 на физическом устройстве ещё не проверялись, в кабинет не загружались. Протокол передачи и ограничения: [TRANSFER-0.2.md](TRANSFER-0.2.md); локальные соответствия 0.2 заменены общими настройками 0.3.

Приложение `5b7af3e5-b60e-4044-a437-8e22d355d804`, пакет `ru.lounge1708.evotorbridge`. UUID версии кабинета `16d3e630-1aa9-4b11-b478-d0c1ee22d8f3` не используется как app_uuid. Ожидаемый терминал: Android 11, Эвотор ОС 6.0.32, Evotor POS 8.25.1.1-865.

## Возможности и ограничения

- Поиск и чтение существующих карточек товаров кассы.
- Выбор количества 1–100; цена, тип и налог берутся из карточки, не подменяются.
- Неизвестные SDK типы и налоги, а также маркированные товары блокируются, потому что SDK v0.6.03 может иначе подставить NORMAL/NO_VAT.
- Открытие одного незакрытого чека по явному подтверждению, затем переход только к редактированию. Прототип не вызывает оплату, печать, удаление, изменение карточек и остатков.
- Непустой текущий чек блокирует операцию. Требуется POS 8.11+, чтобы также действовала защита со стороны SDK при гонке с другим действием на кассе.
- После одной попытки повторная отправка сохраняется заблокированной даже после перезапуска. Таймаут означает неизвестный результат, а не разрешение повторить действие.
- Перечисленные ограничения однократной попытки относятся к старому автономному экрану. Новый экран использует независимый журнал попыток по посещениям столов, серверное резервирование и сопоставление карточек. Это тестовая интеграция, не доказательство бесплатной постоянной установки.

## Сборка

Портативные инструменты находятся в игнорируемой `.local-tools/evotor` внутри рабочего каталога. Системный Java и настройки кассы скрипты не меняют.

1. Получить официальный `repository2-1.xml` в `.local-tools/evotor/repository.xml`.
2. Выполнить `scripts/prepare-toolchain.ps1`: загрузки Java 17, Android command-line tools 19.0 и Gradle 8.9 проверяются по контрольным суммам.
3. С помощью sdkmanager установить `platforms;android-34` и `build-tools;34.0.0` в `.local-tools/evotor/sdk`.
4. Выполнить `scripts/build.ps1`: unit tests, Android Lint, debug APK. Файл копируется в `.release/evotor/1708-kassa-test-0.3.apk`. Предыдущие APK не заменяются.

APK подписан прежним тестовым ключом, versionCode=3. Это не выпуск в production. Устанавливать вне обслуживания гостей; не оплачивать тестовый чек. Перед продолжением кассовой работы проверить и вручную убрать незакрытый тестовый чек обычными средствами кассы.
