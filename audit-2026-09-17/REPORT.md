Рабочая база не использовалась, публикации не было. Отдельные логины персонала не добавлялись.

## Нагрузка: выявлен незакрытый риск

Стенд: Windows, Node 22.23.2, Java 21.0.12.1, Firebase CLI 15.30.1, реальные локальные эмуляторы Auth/Database/Functions. Каждый профиль заполняется синтетической историей за 60 дней до запуска. На исторический заказ приходится также квитанция гостя и запись операции персонала. Живой стол и товар одинаковы во всех профилях.

Серия: 12 гостевых заказов от четырёх пользователей, один заказ персонала и одна правка меню отправляются параллельно. При успехе проверяются уникальные номера, точный остаток, две конкурентные отмены одного заказа, редактирование другого заказа и неизменность всей истории.

| Исторических заказов | Размер исходного JSON | Время серии после очереди | Результат |
|---:|---:|---:|---|
| 0 | 291 байт | 20,07 с | Все результаты подтверждены, проверки целостности пройдены |
| 1000 | 667 023 байта | 24,01 с | Все результаты подтверждены, проверки целостности пройдены |
| 5000 | 3 387 237 байт | 30,27 с | 13 из 14 запросов без подтверждённого результата, HTTP 500 при тайм-ауте |

До изменения уже профиль с 1000 заказов завершался тайм-аутом двух функций; проверка остатка получила 189 вместо ожидаемых 187. В исходном измерителе такие ответы HTTP 500 ещё не попадали в поле `errors`; провал обнаружила проверка остатка. Поэтому пустой `errors` в сохранённом `load-before.json` не означает успешного прогона. Исправленный измеритель явно считает отсутствие callable result ошибкой.

Добавлена очередь корневых транзакций внутри одного процесса Functions. Она уменьшает одновременное повторное вычисление транзакций этого процесса; конкуренция между экземплярами по-прежнему разрешается транзакциями RTDB. Отклонённая операция не блокирует следующие. Это ограниченное улучшение: **профиль 5000 не прошёл, риск перед большим квизом остаётся**. HTTP 500 не доказывает, что заказ не был принят; состояние такой отправки нужно выяснять повтором того же номера операции.

Время включает запуск обработчиков и ограничения локального компьютера. Профили не являются прогнозом скорости production, холодный старт особенно влияет на первый профиль. Здесь не измерялись FPS интерфейса, большой реальный ассортимент или произвольное количество телефонов. Прогон остановился на ошибке профиля 5000; целостность его конечного состояния не подтверждена.

Следующее архитектурное изменение — отдельная компактная область текущей смены для транзакций и отдельный архив, а не только другая папка внутри прежней корневой транзакции. Потребуются перенос данных с проверкой, чтение старых чеков из архива, правила и совместный выпуск клиента/Functions. В текущем проходе перенос данных и автоматическое удаление истории не выполнялись.

Артефакты: `load-before.json`, `load-results.json`. Повтор: `npm run test:load`. Команда намеренно возвращает ненулевой код, если серия не получила все подтверждения или нарушена целостность; она не входит в быстрый зелёный набор тестов.

## Проверка старых данных

Добавлена команда только для чтения локального полного JSON-экспорта RTDB:

```powershell
npm run audit:data -- --input "C:\путь\export.json" --output "C:\путь\report.json"
```

Команда не подключается к Firebase, не меняет экспорт, не назначает цены и идентификаторы. Отчёт не перезаписывает существующий файл и не может быть записан поверх исходного экспорта. В отчёт попадают ключи проблемных заказов/строк и коды причин; примечания гостей и токены не копируются.

Основные причины:

| Код | Что проверить вручную |
|---|---|
| legacy_text_requires_review / missing_price_snapshots | Текстовый формат не содержит надёжных сохранённых цен; текущую цену нельзя выдавать за историческую |
| missing_price_snapshot / invalid_price | Цена отсутствует либо некорректна; корректный ноль допускается |
| ambiguous_product / product_not_found | Несколько совпадений товара либо товар отсутствует; известный ID не заменяется совпадением имени |
| missing_product_id / duplicate_catalog_product_id | Отсутствует постоянная связь или в каталоге повторён ID |
| total_mismatch | Сохранённый итог расходится с суммой корректных строк |
| invalid_order / invalid_item / invalid_quantity / invalid_date | Повреждённая структура, количество или дата |
| unfinished_order_outside_open_session | Незавершённая позиция относится к закрытой или заменённой сессии |

Инструмент проверен семью тестами, включая неизменность источника и запрет перезаписи. `legacy-example.json` и `legacy-example-report.json` показывают работу на синтетических данных. **Экспорт реальной базы не предоставлялся и не проверялся.**
